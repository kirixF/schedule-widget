# ScheduleWidget

Android-приложение с виджетом расписания на сегодня.

## Источник расписания

Выбран прямой запрос к API сайта `rasp.ural-campus.ru`.
Telegram-бот не используется как источник: он сам получает данные с этого же сайта, а читать его ответы из отдельного Android-приложения надежно нельзя без лишних токенов, аккаунтов и зависимости от запущенного бота.

Виджет запускает фоновую задачу, получает список групп через `/api/schedule/college/groups`, находит сохраненную группу, запрашивает сегодняшний день через `/api/schedule/college/group/{guid}` и выводит пары на виджет.
Скрытый `WebView` оставлен запасным вариантом, если API сайта внезапно перестанет отвечать.

## Как пользоваться

1. Установить APK на телефон.
2. Открыть приложение `Расписание`.
3. Ввести группу, например `П-210`, и нажать `Сохранить и обновить`.
4. Добавить виджет на главный экран.

Android сам регулирует точное время фоновых обновлений. Сейчас задан период 30 минут, но система может сдвигать обновления для экономии батареи.

## Сборка

```powershell
.\gradlew.bat :app:assembleRelease
```

Готовый APK будет в:

```text
app/build/outputs/apk/release/app-release.apk
```
