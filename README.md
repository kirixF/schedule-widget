# ScheduleWidget

Android-приложение с виджетом расписания и локальным офлайн-архивом.

## Источник расписания

Приложение напрямую обращается к API сайта `rasp.ural-campus.ru`.
Telegram-бот не используется как источник данных.

После сохранения группы приложение:

1. Получает список групп через `/api/schedule/college/groups`.
2. Запрашивает опубликованное расписание группы через `/api/schedule/college/group/{guid}`.
3. Сохраняет доступные дни в приватный JSON-файл `schedule_archive.json`.
4. Показывает выбранный день в виджете и позволяет переключать сохраненные дни без интернета.

При каждом успешном обновлении актуальный диапазон заменяется свежими данными, а уже сохраненные прошлые дни остаются в архиве.

## Фоновое обновление

Приложение планирует обновление каждый день на `01:00` по часовому поясу телефона.
Используется системный `JobScheduler`, поэтому Android может немного сдвинуть фактический запуск для экономии батареи или до появления сети.
После перезагрузки телефона задача планируется повторно.

## Как пользоваться

1. Установить APK на телефон.
2. Открыть приложение `Расписание`.
3. Ввести группу, например `П-210`, и нажать `Сохранить и обновить`.
4. Выбрать нужную дату в разделе `День расписания`.
5. При необходимости добавить виджет на главный экран.
6. В виджете нажимать дни в полоске `ПН–ВС`, а стрелками листать недели.
7. При необходимости изменить высоту виджета: компактный режим показывает одну пару, полный режим — до четырех.
